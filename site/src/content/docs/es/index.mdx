## Esto es lo que hace

Ejecuta la comprobación en cualquier proyecto. Lee tus archivos y te dice, en
una pantalla, si ya puedes escribir código — con un aviso real, porque una
salida perfecta parecería una maqueta:

<div class="sdd-term">
<div class="sdd-term-bar"><span>./scripts/check-sdd-gate.sh</span><span>salida literal</span></div>

```
Checking SDD gate in: /Users/jk/my-project
[OK] SDD policy check
[OK] 001-auth has approval status section
[OK] 001-auth approved with minimum plan consistency signals
[OK] 001-auth approved with checklist tasks
[OK] User consent log present for execution stage: .sdd/user-consent.log
[OK] 001-auth has recorded user consent
[WARN] 002-billing not approved yet (implementation gate should remain closed)

Compuerta / Gate: ABIERTA / open — 1 spec(s) aprobada(s) y consentida(s) / approved and consented
```

</div>

<p class="sdd-term-note">El script emite sus comprobaciones en inglés; solo las líneas de cierre son bilingües. Traducirlas aquí sería mentir sobre lo que vas a ver.</p>

## O abre el tablero visual

Un comando, desde la carpeta de tu proyecto:

```bash
npx @juanklagos/sdd-mcp@latest --http
```

Se abre el builder en tu navegador, con el servidor al que conectas tu agente.
Si prefieres una ventana propia, [SDD Desk](./download/) es el mismo tablero
como app de escritorio.
