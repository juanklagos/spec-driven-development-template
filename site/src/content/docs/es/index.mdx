## Esto es lo que hace

Ejecuta la comprobación en cualquier proyecto. Lee tus archivos y te dice, en
una pantalla, si ya puedes escribir código:

```
gate: bloqueado   3 errores · 3 avisos · 2/5 aprobadas
  029-checkout        aprobada, pero sin consentimiento registrado
  031-pagos           plan.md no menciona los requisitos aprobados
no hay código sin spec aprobada
```

Esa salida es el producto entero. Todo lo demás existe para que sea verdad.
